### Developer life

- Debugging until the terminal gets bored and starts judging me
- "It's not a bug — it's an undocumented feature" — every developer ever
- My code works, I don't know why. My code breaks, I also don't know why
- If at first you don't succeed, call it version 1.0
- 99 little bugs in the code... take one down, patch it around... 127 little bugs in the code
- Works on my machine™ (please don't test it on yours)

### About

- Full-stack development & web scraping — from raw HTML/API parsing to normalized, production-ready data
- Automation: cron pipelines, serverless functions, and self-hosted services
- Ren'Py / visual novel tooling and community projects
- Zero-dependency-first mindset: small, fast, and portable modules
